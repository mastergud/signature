# Signatures e-mail — images

Images utilisées par les signatures e-mail Vitralux / Aluco / Vitrophy.

Servies via jsDelivr (version figée `v1`) :

    https://cdn.jsdelivr.net/gh/mastergud/signature@v1/images/<fichier>.png

Pour modifier une image : remplacer le fichier, committer, puis créer une nouvelle étiquette (`v2`, …)
et régénérer les signatures avec la nouvelle version.
